# CS 370 Project Reflection

## Briefly explain the work that you did on this project: What code were you given? What code did you create yourself?

For this project, I worked on a pirate intelligent agent that used reinforcement learning to navigate a maze and reach a treasure. I was given starter code that included the game environment, maze structure, experience replay functionality, and some of the supporting functions needed to run and train the agent. I created and completed the deep Q-learning portion of the project, including the training logic that allowed the pirate agent to learn from its previous actions and improve its decisions over time.

The main goal was to train the agent to successfully find the treasure by balancing exploration and exploitation. During training, the agent explored different paths through the maze, stored its experiences, and used those experiences to update the neural network. Over time, the agent became more consistent at selecting actions that led toward the goal.

## What do computer scientists do and why does it matter?

Computer scientists solve problems by designing algorithms, developing software, analyzing data, and creating systems that can perform useful tasks. Their work matters because software and computer systems are used in nearly every industry, including healthcare, transportation, finance, education, entertainment, and communication. Computer scientists help make these systems more efficient, reliable, secure, and useful for the people who depend on them.

This project showed me that computer science is not only about writing code. It also involves understanding a problem, selecting an appropriate solution, testing that solution, and improving it based on the results.

## How do I approach a problem as a computer scientist?

I approach a problem by first breaking it into smaller parts and identifying what the program needs to accomplish. From there, I look at the available tools, algorithms, and data and determine which approach is most appropriate. In this project, that meant understanding the maze environment, identifying the possible actions available to the agent, and determining how reinforcement learning could be used to improve the agent's behavior.

I also learned the importance of testing and adjusting a solution instead of expecting the first version to work perfectly. With the pirate agent, I had to observe the training results, make changes to the learning process, and continue testing until the agent was able to solve the maze consistently. I can apply this same process to future software development and computer science projects.

## What are my ethical responsibilities to the end user and the organization?

As a computer scientist, I have a responsibility to create systems that are safe, reliable, fair, and respectful of users. This includes protecting user data, considering privacy and security, testing software carefully, and avoiding designs that could cause unnecessary harm. When artificial intelligence is involved, developers should also consider whether the system is making biased or unpredictable decisions and whether users understand how the technology is being used.

I also have responsibilities to the organization developing the system. This includes writing maintainable code, being honest about the limitations of a program, protecting sensitive information, and making sure the software meets its intended requirements. Ethical decision-making is important because computer systems can affect both the organization and the people who use them.
